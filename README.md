# Estudos em Análise de Dados

Repositório com minha evolução nos estudos para me tornar analista de dados, cada dia tentando melhorar 1% e buscando novos conhecimentos.

## Conteúdo

- `sql/` — exercícios de SQL
 - `00_criar_tabela_vendas.sql` — script que cria a tabela usada nos exercícios
 - `01_criar_tabelas_produtos_clientes.sql` — script que cria as tabelas de produtos e clientes
 - `aula01_select.sql` — SELECT, colunas calculadas e AS
 - `aula02_where_order_by.sql` — filtros com WHERE, AND/OR, IN e ordenação
 - `aula04_agregacoes.sql` — DISTINCT, COUNT, SUM, AVG, MIN, MAX e ROUND
 - `aula05_like_between_group_by.sql` — LIKE, BETWEEN e GROUP BY
 - `aula06_having.sql` — HAVING, WHERE vs HAVING e ticket médio
 - `aula07_joins.sql` — INNER JOIN, LEFT JOIN e a pegadinha do COUNT
 - `aula08_subconsultas_cte.sql` — subconsultas (IN, NOT IN) e CTEs com WITH
